# CSCI-631: Foundations of Computer Vision

A collection of programming assignments from **CSCI-631: Foundations of Computer Vision** at Rochester Institute of Technology.  
This repository showcases implementations of fundamental computer vision concepts.

## 📁 Assignments

| Folder | Description |
|--------|-------------|
| [`01-image-handling`](./01-image-handling) | Basic image manipulation such as cropping, mirroring, rotation, ect.... |
| [`02-color-spaces`](./02-color-spaces) | Underwater image enhancement and panorama stitching via manual point selection. |
| [`03-template-matching`](./03-template-matching) | Custom correlation, separable filters, template matching, and object detection with non‑maximal suppression. |
| [`05-shape-detection`](./05-shape-detection) | Binary image processing to classify shapes, size, and color. |
| [`06-fourier-hybrid`](./06-fourier-hybrid) | Fourier transforms and hybrid image generation. |
| [`07-feature-detection`](./07-feature-detection) | Harris corner detection, SIFT, RANSAC, and automated panorama stitching. |
| [`08-3d-stereo`](./08-3d-stereo) | Stereo vision of 3d images. |
| [`09-optical-flow`](./09-optical-flow) | Optical flow of two consecutive frames. |
| [`11-character-recognition`](./11-character-recognition) | Character recognition system classifier for handwritten text. |

## 🚀 Getting Started

Each assignment folder contains its own `README.md` with detailed instructions, prerequisites, and examples.  
Most assignments use Python 3.10+ and require `numpy`, `opencv-python`, and occasionally `torch`, `open3d`, or `matplotlib`.

1. Navigate to an assignment folder.
2. Install the required packages (see the folder's `requirements.txt` or the README).
3. Follow the “How to Run” section in that assignment's README.
